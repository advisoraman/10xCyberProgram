Cyber + GRC
Week 1
Security Fundamentals

  • AAA model — Authentication, Authorization, Accounting
  • Types of threat actors — Nation-state, Insider, Hacktivists, Cybercriminals
  • Attack types — Phishing, Social engineering, MITM, DoS/DDoS, Ransomware, APT
  • Security controls — Preventive, Detective, Corrective, Compensating
  • Defense-in-depth strategy
Operating Systems Security
  • Linux — file permissions (chmod/chown), users & groups, sudoers LAB
  • Linux — processes, cron jobs, /var/log, syslog, journalctl LAB
  • Linux — bash scripting basics: loops, conditionals, file parsing LAB
  • Windows — Active Directory basics: domains, OUs, users, groups
  • Windows — Group Policy Objects (GPO), local security policy
  • Windows — Event Viewer: Event IDs 4624, 4625, 4688, 4720, 4732 SOC
  • Windows — Registry security, startup locations (HKLM Run keys)
Week 2–3 — Lab Setup & Practice
Lab Environment
  • Hypervisor setup — VirtualBox / VMware with NAT + host-only networks LAB
  • Deploy Kali Linux, Windows Server 2019 eval, Ubuntu Server LAB
  • Deploy vulnerable targets — DVWA, Juice Shop, Metasploitable2 LAB
  • GRC intro — Governance vs Risk vs Compliance mental model
  • Frameworks overview — NIST CSF, ISO 27001, CIS Controls v8, SOC 2
  • Indian regulatory landscape — IT Act 2000, DPDP Act 2023, CERT-In directions 🇮🇳
Week 3 — Consolidation & Deep Practice
Security Concepts — Reinforcement Labs
  • CIA Triad mapping exercise — analyse 5 real Indian breach case studies (AIIMS, CoWIN, BigBasket, Dominos, MobiKwik) and identify which properties were violated LAB
  • Security controls gap analysis — given a 20-person CA firm's current setup, identify missing preventive/detective/corrective controls and prioritise remediation LAB
  • Threat actor profiling exercise — build a 1-page profile of APT28 and Lazarus Group covering motivation, capability, typical TTPs, and Indian targets LAB
OS Security — Advanced Practice
  • Linux hardening checklist — apply CIS Benchmark Level 1 controls to your Ubuntu VM: disable root SSH, configure fail2ban, set password aging, audit cron LAB
  • Windows hardening — enable audit policies via GPO, configure Windows Defender, disable unused services, verify Event Log settings LAB
  • Write your first bash security audit script — checks for world-writable files, empty passwords, SUID binaries, and listening services LAB
Lab Verification Checkpoint
  • Verify all VMs are running and accessible: Kali → Metasploitable2 ping, DVWA login, Juice Shop accessible, Windows Server RDP working
  • Take VM snapshots — "Clean Install" baseline for each VM before any testing begins LAB
  • Quiz yourself — 30-question foundations review covering CIA, AAA, attack types, OS concepts, port numbers, and Indian regulatory basics

Cryptography & PKI
Week 3 · Encryption · Hashing · Certificates
Crypto
Encryption Concepts
  • Symmetric encryption — AES-128/256, DES, 3DES; block vs stream ciphers
  • Asymmetric encryption — RSA, ECC; public/private key pairs explained
  • Key exchange — Diffie-Hellman, ECDH
  • Hashing — MD5, SHA-1, SHA-256, SHA-3; collision resistance
  • HMAC — message authentication codes, use in APIs and TLS
  • Salting passwords — bcrypt, Argon2 vs unsalted MD5 LAB
PKI & TLS
  • PKI components — CA, RA, CRL, OCSP, certificate chain of trust
  • X.509 certificates — structure, fields, SAN, wildcard certs
  • TLS 1.2 vs TLS 1.3 handshake — cipher suites, perfect forward secrecy
  • Inspecting TLS in Wireshark — ClientHello, ServerHello, Certificate LAB
  • Common crypto attacks — downgrade, BEAST, POODLE, padding oracle
  • OpenSSL basics — generate keys, sign certs, verify, inspect TOOL
  • SSH key pairs — ed25519 vs RSA, authorized_keys, agent forwarding LAB

Network Security & Protocols
Week 4–5 · Protocols · Scanning · Firewalls · Wireless
Cyber
Week 3
Protocol Deep Dive
  • TCP/IP model — IP, TCP, UDP; flags (SYN, ACK, RST, FIN, PSH)
  • DNS — A, AAAA, MX, CNAME, PTR records; zone transfers; DNS poisoning
  • HTTP/S — methods, status codes, headers, cookies, HSTS
  • DHCP — lease process, DORA, rogue DHCP attacks
  • ARP — address resolution, ARP spoofing / poisoning attacks
  • ICMP — ping, traceroute, ICMP tunneling
  • Common ports 1–1024 memorization + key service ports Security+
Packet Analysis
  • Wireshark — capture filters vs display filters, follow TCP stream TOOL LAB
  • Wireshark — identify credentials in cleartext protocols (Telnet, FTP, HTTP) LAB
  • Wireshark — detect ARP spoofing, port scans, DNS anomalies LAB
  • tcpdump — command-line packet capture for SOC/IR use TOOL
Week 4
Scanning & Reconnaissance
  • Nmap — host discovery, port scans (SYN, connect, UDP, stealth) TOOL LAB
  • Nmap — OS fingerprinting (-O), service version detection (-sV), NSE scripts LAB
  • Passive recon — Shodan, theHarvester, WHOIS, dnsdumpster TOOL
  • Google Dorking — finding exposed assets, login pages, sensitive files
Firewalls, IDS/IPS & Architecture
  • Firewall types — packet filter, stateful, NGFW, WAF — use cases
  • iptables / nftables basics — allow, deny, chain rules LAB
  • IDS vs IPS — Snort/Suricata rules, signature vs anomaly-based detection
  • Network segmentation — DMZ, VLANs, jump server / bastion host
  • VPN types — IPSec, SSL/TLS VPN, split tunneling; Zero Trust vs VPN
  • Wireless security — WEP/WPA/WPA2/WPA3; evil twin attacks, deauth attacks CEH
  • Proxy servers, NAT, load balancers — security implications
